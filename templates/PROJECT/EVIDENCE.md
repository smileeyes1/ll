# Evidence Ledger

Every important claim must have a reproducible proof.

| ID | Claim | Evidence | Commit/Run | Status |
|---|---|---|---|---|
| E-001 | Project initialized | Factory output + structure tests | first verified run | pending |

## Evidence rules
- No evidence → no VERIFIED claim.
- A file existing is not proof that its contents are valid.
- A workflow file existing is not proof that it ran.
- An artifact is valid only if it exists, is non-empty, and passes the relevant checks.
